# SentinelAI Machine Learning Subsystem

Contains dataset preparation, training pipelines, and evaluation routines for SentinelAI.

## Subdirectories
- `datasets/`: Raw and processed datasets (e.g., HTTP payload samples and network flows).
- `notebooks/`: Jupyter notebooks for exploratory data analysis and model prototyping.
- `training/`: Production training scripts outputting serialized artifacts to `ai-service/app/models/`.
- `evaluation/`: Independent evaluation metrics, confusion matrices, and validation reports.
